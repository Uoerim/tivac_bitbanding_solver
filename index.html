📚 GPIO Data Masking Theory

Address Masking Formula

mask = (address - base_address) / 4

Each address offset corresponds to a different bit mask

Write Operation

new_port = (old_port & ~mask) | (write_value & mask)

Only bits where mask=1 are affected by the write

Read Operation (Cell Display)

displayed_value = port_value & mask

Each cell shows only the bits that its mask allows

Common Mask Examples

Offset 0x04 → Mask 0x01 (bit 0)
Offset 0x08 → Mask 0x02 (bit 1)
Offset 0x3C → Mask 0x0F (bits 0-3)
Offset 0x40 → Mask 0x10 (bit 4)
Offset 0x7C → Mask 0x1F (bits 0-4)
Offset 0x3FC → Mask 0xFF (all bits)

⚠️ Important: When Do DIR/DEN/PUR Matter?

📊 For the Memory Table (Exam Questions)

The memory table values depend ONLY on:

  • The data latch value (what you last wrote via any masked alias)
  • The mask calculated from the address

DIR, DEN, PUR do NOT affect the memory table values. Even if all registers were 0, the table would show the same values.

💡 For Hardware to Work (LEDs, Buttons)

To make the write "work electrically" on the real Tiva board:

  • DIR = 0x0F → PF0–PF3 are outputs (for LEDs), PF4 is input (for button)
  • DEN = 0x1F → PF0–PF4 have digital I/O enabled
  • PUR = 0x10 → PF4 has pull-up so button reads HIGH when not pressed

The CPU can always write to memory; these settings only decide whether the pins actually see the effect.

📝 Example

Writing 0x0F to 0x4002503C (mask 0x0F) sets latch bits 0–3 to 1.

The memory table shows 0x00...0x0F pattern regardless of DIR/DEN/PUR.

But LEDs only light up if those bits are configured as outputs (DIR=1) and digital enabled (DEN=1).
